# ✈️ EuroFlight Analyst: CSV Data Processing & Visualization

**EuroFlight Analyst** is a robust console-based Python application designed to process and analyze flight departure data from major European airports. This project demonstrates core programming excellence in data manipulation, file I/O, and interactive data visualization.

---

## 🚀 Key Features

- **📊 Comprehensive Data Analysis**: Processes complex CSV files containing flight departure records to extract meaningful insights.
- **🎨 Interactive Visualization**: Uses the `graphics.py` library to generate visual representations of flight patterns and statistics.
- **🛡️ Robust Input Validation**: Features advanced error handling and user input validation to ensure reliable data processing.
- **📁 CSV File I/O**: Efficiently reads, filters, and manages large datasets stored in CSV format.
- **🖥️ User-Friendly Console Interface**: A clean and intuitive command-line interface for navigating through different analytical reports.

---

## 🛠️ Tech Stack & Skills

*   **Language**: Python 3.x
*   **Libraries**: `graphics.py` (for custom visualization), `csv` (for data handling)
*   **Concepts**: Data Filtering, File Handling, Input Sanitization, Algorithm Design

## ⚙️ How to Run

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/rasanjana-54/EuroFlight-Analyst-CSV-Data-Processing-Visualization.git
    ```

2.  **Install Graphics Library**
    Make sure you have the `graphics.py` file in your project directory or install it via pip if using a wrapper:
    ```bash
    # Ensure Python is installed
    python --version
    ```

3.  **Prepare Data**
    Place your European flight data CSV file in the root directory.

4.  **Execute the Analyst**
    ```bash
    python main.py
    ```
